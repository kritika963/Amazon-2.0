# Amazon Clone

A front-end Amazon Clone website built using HTML and CSS.

## Features

* Amazon-inspired homepage design
* Navigation bar with search functionality UI
* Hero section and product category cards
* Responsive layout
* Footer similar to Amazon

## Technologies Used

* HTML5
* CSS3

## Purpose

This project was created for learning and practicing front-end web development concepts such as page layout, flexbox, CSS styling, and responsive design.
